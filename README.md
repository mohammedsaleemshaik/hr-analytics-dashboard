# 📊 HR Analytics Dashboard

## Overview
This project analyzes employee workforce data using SQL, Google BigQuery, and Looker Studio.

## Tools Used
- SQL
- Google BigQuery
- Looker Studio

## Dashboard Features
- Total Employees
- Average Age
- Average Salary
- Attrition Rate
- Employees by Department
- Average Salary by Job Role
- Gender Distribution
- Job Satisfaction
- Attrition by Education Field
- Employee Age Distribution

## Dataset
IBM HR Analytics Employee Attrition Dataset
